// PROJECT 01 — INFRASTRUCTURE
Bespoke Home Lab & Server
Problem
Needed a centralised, powerful dev environment without cloud vendor lock-in — for running containerised apps, VMs, and media services at minimal cost.
Architecture
Selected cost-optimised hardware and deployed Proxmox VE as the hypervisor, managing VMs and LXC containers across isolated network segments. ZFS for storage redundancy, Nginx Proxy Manager for SSL-terminated reverse proxying, and automated backup pipelines via Bash scripting.
Stack
Proxmox VEDebianDockerNginx PMZFSBash
Key Win
Achieved near-silent, low-power operation via CPU under-volting and dynamic fan curve control — without any thermal throttling under typical workloads.
// PROJECT 02 — CLOUD STORAGE
Private Cloud Storage Network
Problem
Commercial cloud storage meant ongoing subscription costs and surrendered data sovereignty. Required full control, encryption, and seamless cross-device access.
Architecture
Deployed Nextcloud in a Proxmox LXC container behind an Nginx reverse proxy with automatic Let's Encrypt SSL renewal. Rclone handles encrypted incremental backups to offsite storage. Native sync clients on all devices ensure seamless availability.
Stack
NextcloudNginxLet's EncryptRcloneProxmox LXCMariaDB
Key Win
PHP-FPM tuning and aggressive cache headers reduced remote file access latency by over 60% while maintaining full end-to-end encryption.
