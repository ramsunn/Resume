Bespoke Home Lab & Server

The Problem: I needed a centralized, powerful, and efficient environment for development, running containerized applications, and serving media, without relying entirely on public cloud services.

My Process: I sourced cost-effective hardware and installed Proxmox as a hypervisor to manage multiple virtual machines and containers. I configured secure network access, automated backups, and set up Docker for application deployment.

Tech Stack: Proxmox VE, Debian Linux, Docker, Nginx Proxy Manager, ZFS for storage.

Challenges & Solutions: A key challenge was silent, low-power operation. I solved this by carefully selecting components and using software tools to under-volt the CPU and control fan speeds dynamically.

Personal Cloud Storage Network

The Problem: I wanted a robust, private, and secure alternative to commercial cloud storage services, offering full control over my data and high availability across my devices.

My Process: I designed and implemented a multi-device synchronization system using Nextcloud hosted on my home server. I configured secure remote access via a reverse proxy and implemented a robust backup strategy to external storage.

Tech Stack: Nextcloud, Apache/Nginx, Let's Encrypt (for SSL), Rclone, Proxmox LXC.

Challenges & Solutions: Ensuring secure external access while maintaining performance was crucial. I leveraged Nginx Proxy Manager to handle SSL termination and route traffic efficiently, enhancing security and simplifying certificate management.

OS Prototyping & Bug Triage

The Problem: Exploring new operating systems and their nuances often involves significant setup and troubleshooting. I aimed to streamline this process and actively contribute to improving OS stability.

My Process: I set up multiple dedicated environments (virtual machines, multi-boot systems) to rigorously test pre-release and custom OS builds, including various Linux distributions and macOS (Hackintosh). I meticulously documented bugs, identified root causes, and provided actionable feedback to developer communities and beta programs.

Tech Stack: VirtualBox, VMware, KVM/QEMU, various Linux distributions (Arch, Fedora, Ubuntu), macOS (OpenCore/Clover), custom kernel patches.

Challenges & Solutions: Hardware compatibility and driver issues were common, especially with Hackintosh builds. My solution involved deep dives into hardware specifications, EFI configuration, and precise driver selection, often involving compiling custom kexts or kernel modules.
