Bespoke Home Lab & Server

The Problem: I needed a centralized, powerful, and efficient environment for development, running containerized applications, and serving media, without relying entirely on public cloud services.

My Process: I sourced cost-effective hardware and installed Proxmox as a hypervisor to manage multiple virtual machines and containers. I configured secure network access, automated backups, and set up Docker for application deployment.

Tech Stack: Proxmox VE, Debian Linux, Docker, Nginx Proxy Manager, ZFS for storage.

Challenges & Solutions: A key challenge was silent, low-power operation. I solved this by carefully selecting components and using software tools to under-volt the CPU and control fan speeds dynamically.
